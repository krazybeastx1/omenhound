      Graph Ingestion
      
          
      
            
            
            
          
      
          
      
            
      Upload a Graph JSON file to ingest into the server. Requires Write API token.
      
            
      
              
              
            
      
            
      
              
              
            
      
            
      
              Domain scope
              
      Choose the domain this file belongs to. Leave blank to import every domain the file contains. Entities that belong to a different domain are rejected unless you choose to skip them.
      
              
      
                
      
                  
                  
                  
                
      
                
      
                  
                  
                
      
                
      
                  
                  
                
      
                
      
                  
                  
                
      
              
      
            
      
            
            
      Off by default: an ingest merges into the graph you already have. With a domain selected, replace removes only that domain's existing data; other domains are never touched.
      
            
      
            
      
            
      
              
              
            
      
            
      
              Expected Graph JSON Format
              
      {"nodes":[{"id":"S-1-...","kind":"User","name":"...","domain":"...","sam_account_name":"...","distinguished_name":"...","props":{}}],"edges":[{"source":"S-1-...","target":"S-1-...","kind":"GenericAll"}],"meta":{"collector":"ldap","version":"...","domain":"...","started_at":"...","finished_at":"..."}}
      
            
      
            
      
            
      
              
      ⚠ Delete ALL graph data (global, every domain)
      
              
      Remove every node and relationship the server currently holds, across every domain and ingestion batch. This cannot be undone. To remove only one batch or one domain, use the Ingestion Management tab.
      
              
      Current graph: —
      
              
      
                
              
      
            
      
          
      
          
      
            
      Every import is tracked as a batch with its own provenance. Removing a batch or a domain only deletes the records that are safe to remove; records also contributed by another import, and every other domain, are preserved.

      Collection & Enumeration Guidance
      
          
      
            
      
              
      LDAP Collection
      
              
        
                
      • -c group — Users, groups, computers, membership
        • 
                
      • -c objectprops — Extended properties (SPNs, OS, etc.)
        • 
                
      • -c acl — Security descriptors → ACL edges
        • 
                
      • -c container — OUs, GPOs, containers, GPLinks
        • 
                
      • -c trusts — Domain trusts
        • 
              
      
            
      
            
      
              
      SMB/RPC Collection
      
              
        
                
      • -c session — Active sessions (HasSession)
        • 
                
      • -c localadmin — Local admins (AdminTo)
        • 
                
      • -c rdp — RDP access (CanRDP)
        • 
                
      • -c dcom — DCOM execution (ExecuteDCOM)
        • 
                
      • -c psremote — WinRM/PSRemoting (CanPSRemote)
        • 
                
      • -c loggedon — Logged-on users (HasSession)
        • 
              
      
            
      
            
      
              
      Authentication
      
              
        
                
      • Simple bind (default) — DN/UPN + password
        • 
                
      • --auth-method ntlm — NTLMSSP bind
        • 
                
      • --hashes NT — Pass-the-hash (NTLM)
        • 
                
      • -k / --auth-method kerberos — Kerberos (password, hash, AES, ccache)
        • 
              
      
            
      
            
      
              
      Key Flags
      
              
        
                
      • --ldaps — Enforce LDAPS (required for writes)
        • 
                
      • --password-stdin — Read password from stdin
        • 
                
      • --zip — Output BloodHound CE v5 archive
        • 
                
      • --out file.json — Output Graph JSON
        • 
                
      • --push http://host:8080 — Push directly to server
        •
